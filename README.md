# Mouse Utilities (mutils)

A Rust workspace for recording, segmenting, and simulating human-like mouse
movements.

This workspace provides a complete toolkit for working with mouse gesture data.
See the README files in each crate for detailed information on features,
installation, and usage:

- **[segments](./segments)** - Core library for segmenting mouse position
  samples into gesture segments
- **[recorder](./recorder)** - Binary application for recording mouse movements
  to disk
- **[mousesim](./mousesim)** - Library and binary for simulating mouse movements
  using recorded data
